# Telefonda APK oluşturma
1. ZIP'i aç.
2. İçindeki dosyaları GitHub'da yeni repository'nin köküne yükle.
3. Actions sekmesinden **Build JARVIS APK** iş akışını aç.
4. **Run workflow** seç.
5. Başarılı çalışmadan `JARVIS-debug-apk` artifact'ini indir.
6. APK'yı telefonda kur. Yalnızca kendi oluşturduğun ve güvendiğin pakete kurulum izni ver.

Hata çıkarsa Actions logunun ekran görüntüsünü veya hata metnini paylaş. Yeşil başarılı derleme olmadan APK'nın çalıştığını varsayma.
